# Deeptarka Bhattacharyya — Product Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript. It uses only career facts and metrics present in the supplied resume.

## Preview locally
1. Keep `index.html` and `resume.pdf` in the same folder.
2. Open `index.html` in a browser. An internet connection is needed for the Google Fonts; the site still works without them.

## Publish using GitHub Pages
1. Create a GitHub repository (for example, `deeptarka-portfolio`).
2. Upload `index.html`, `resume.pdf`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, GitHub will show the public URL.

## Before publishing
- Check that the resume PDF is the version you want to make public.
- Confirm that the contact details and LinkedIn URL are current.
- Verify that all figures are approved for public use. The metrics and role details are reproduced from the uploaded CV.
- Consider using a custom domain if desired.

This site is a static portfolio; it does not collect visitor data or use analytics.
